# Israeli Scholarship Quick-Reference Table

A consolidated lookup for the major Israeli higher-education scholarships referenced by this skill. Use as a fast filter before deep-diving into any specific track. All amounts are illustrative and refresh annually, always verify on the source URL listed in the SKILL.md Reference Links table.

## Universal-eligibility (most students should check)

| Scholarship | Profile filter | Typical grant | Application timing |
|---|---|---|---|
| PEREACH (פר"ח) | Any undergraduate | NIS 7,000 (~114 hrs) or NIS 10,000 (140 hrs) | תשפ"ז cycle: opens September, first-come-first-served until ~November (NOT May-September) |
| MilGo (MoE socioeconomic) | BA / hand-engineer / mechina at MALAG/MAHAT institution | Tier A NIS 12,480 / B NIS 10,000 / C NIS 7,500 / D NIS 5,000 (4-tier structure) | Cycle opens December via Milgapo |
| University merit at admission | Incoming freshman with strong bagrut + psychometric | One-time grant per institution; HUJI/TAU/Technion vary | Automatic at registration |

## Stacking rules (cross-cutting)

- MoD periphery scholarship: cannot stack with another periphery scholarship.
- Iron Swords tuition support and Mimadim LiLimudim: cannot be received in the same academic year.
- Iron Swords NIS 1,100 + NIS 2,000 child supplement: stacks with PEREACH, MilGo, Pikadon, PEREACH miluim supplement.
- Rothschild USD 75,000/year: ceiling on OTHER external funding (not the Rothschild itself).
- Rashi / ISEF: must declare all received grants in application; under-declaration risks revocation.
